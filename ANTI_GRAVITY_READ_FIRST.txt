==================================================
4. PROJECT PURPOSE
==================================================

This is a Flutter Wallet Demo / Portfolio project.

The project is DEMO ONLY.

It must NOT process real money.

It must NOT connect to real banks.

It must NOT contain real payment credentials.

It must NOT contain real credit/debit card data.

It must NOT contain production API secrets.

Use Mock/Demo repositories and demo data.

The architecture should allow a future backend/API implementation
without rebuilding the entire UI.

==================================================
6. SECURITY RULES
==================================================

NEVER put these inside source code:

- API keys
- Private keys
- Passwords
- Tokens
- Database credentials
- Payment credentials
- Production secrets

NEVER:

- Disable SSL verification.
- Store real financial credentials.
- Store real card CVV.
- Treat client-side validation as sufficient for financial operations.
- Pretend demo balance is real money.
- Connect directly to a real financial provider from the Flutter UI.

If a real backend is introduced in the future, it must handle:

- Authentication
- Authorization
- Server-side validation
- Secure API communication
- Audit logging
- Rate limiting where appropriate
- Secure secret management

9. ARCHITECTURE RULE
==================================================

Keep business logic out of UI widgets.

Do not put API/repository calls directly into presentation widgets.

Prefer a structure similar to:

lib/
  core/
    constants/
    errors/
    routing/
    theme/
    localization/
    utils/

  features/
    auth/
      data/
      domain/
      presentation/

    wallet/
      data/
      domain/
      presentation/

    transactions/
      data/
      domain/
      presentation/

    profile/
      data/
      domain/
      presentation/

  shared/
    widgets/
    models/

The exact structure may differ if the existing project already has
a good architecture.

Do not change a working architecture just to match this structure
exactly.
