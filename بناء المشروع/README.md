# منصة محفظة النجم الرقمية — AL NAJM DIGITAL WALLET PLATFORM

منظومة مالية مصرفية متكاملة وقابلة لإعادة التسمية والتخصيص (White-Label Digital Wallet Platform)، مخصصة لشركات الصرافة والتحويلات المالية، مع تطبيق نموذج أولي كامل لـ **شركة النجم للحوالات والصرافة (النجم بلس)**.

---

## 🏗️ البنية المعمارية والتقنيات (Architecture & Tech Stack)

- **تطبيق فلاتر المزدوج (Windows Desktop & Mobile):** Flutter / Dart (Clean Architecture - Data / Domain / Presentation / Core) مهيأ بالكامل للعمل على **نظام ويندوز المكتبي (Win32 / C++)** و**الهواتف الذكية (Android & iOS)** مع نظام تجاوب ذكي (Adaptive Scaffold & Responsive Layout).
- **الخادم وواجهات البرمجة:** PHP REST API (عمارة نمطية مع معالجة طلبات المصادقة، المحافظ، التحويلات، صرف العملات، والتحقق من الهوية).
- **قاعدة البيانات والسحابة:** Supabase (PostgreSQL) مع تفعيل سياسات الأمان على مستوى الصفوف (Row Level Security - RLS).
- **لوحة التحكم المركزية:** HTML5/CSS3/JS تدعم الوضعين الفاتح والداكن (Light/Dark Mode)، مع نظام إدارة الجلسات والأجهزة لموظفي خدمة العملاء والرقابة.
- **التوافق اللغوي:** دعم كامل للعربية (RTL-First) والإنجليزية (LTR).
- **دليل المنصات:** [دليل تشغيل الويندوز والهواتف](PLATFORM_GUIDE_WINDOWS_MOBILE.md).

## 🛡️ معايير السلامة المالية والأمان (Financial Safety & Security)

- **السلطة المالية للخادم:** العميل (تطبيق الهاتف) لا يملك صلاحية تعديل الأرصدة أو تأكيد العمليات؛ جميع العمليات المالية تنفذ ذرياً (Atomic Transactions) عبر الخادم وقاعدة البيانات.
- **الحسابات الدقيقة:** استخدام أنواع البيانات العشرية الدقيقة (`DECIMAL`) ومنع الأعداد العشرية العائمة (`Float`) لمنع أخطاء التقريب.
- **إدارة الأجهزة والجلسات:** تطبيق قيد صارم بحد أقصى 3 أجهزة نشطة في نفس الوقت، وحد تراكمي 10 أجهزة للحساب، مع تمكين الإدارة من إخراج الجلسات عن بُعد.
- **عزل المفاتيح السرية:** منع وضع مفاتيح `service_role` أو كلمات مرور قواعد البيانات داخل كود التطبيق أو Git نهائياً.
