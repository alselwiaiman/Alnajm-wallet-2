# دليل تشغيل وبناء نظام محفظة النجم بلس (Windows Desktop & Mobile)

تم تحويل وتخصيص مشروع **محفظة النجم بلس (Al-Najm Plus)** ليعمل بكفاءة فائقة كنظام برمجي متكامل ومخصص لكل من:
1. **أجهزة سطح المكتب ونظام ويندوز (Windows Desktop 10/11 - Win32/C++ Engine)**
2. **الهواتف الذكية (Android Phones & Apple iOS iPhones)**

---

## 🏛️ 1. الهيكلية المعمارية ثنائية المنصة (Dual-Platform Architecture)

```
تطبيق النجم/
│
├── 05_AL_NAJM_DEMO/                    # النسخة التجريبية الحية بهوية النجم بلس

│   │   │   ├── flutter_window.cpp      # نافذة الويندوز وإدارة المقاسات (1280x800)
│   │   │   ├── win32_window.cpp        # معالجة رسائل الويندوز وHigh-DPI
│   │   │   ├── Runner.rc               # ملف الموارد وهوية البرنامج على الويندوز
│   │   │   └── runner.exe.manifest     # التوافق مع Windows 10 وWindows 11

│   │   ├── app/

│   │   │   └── src/main/

│   │   │       └── kotlin/.../MainActivity.kt # المشغل الأصلي للأندرويد
│   │   ├── build.gradle

│   │
│   ├── ios/                            # الكود الأصلي لهواتف آبل (Swift & Info.plist)
```

## 💻 2. المزايا المخصصة لنسخة الويندوز (Windows Desktop Edition)

عند تشغيل التطبيق على نظام ويندوز أو شاشة كمبيوتر واسعة:
1. **الشريط الجانبي المالي (Desktop Financial Sidebar)**:
   - شعار وهوية النجم بلس باللون العنابي والذهبي مع إشارة "DESKTOP PRO".
   - بطاقة حالة المستخدم ورقم الحساب ومستوى التوثيق المالي (موثق المستوى 2).
   - قوائم تنقل كاملة مع عدادات العمليات والإشعارات.
   - أزرار سريعة للغة والمظهر وتسجيل الخروج الآمن.
2. **محاكي الهاتف المدمج على الويندوز (Mobile Simulator Mode)**:
   - ميزة حصرية تتيح للمستخدم أو المطور النقر على زر "محاكي شاشة الهاتف" في الشريط الجانبي لتتحول واجهة الويندوز فورياً إلى إطار هاتف ذكي تفاعلي مجسم مباشرة داخل شاشة الكمبيوتر!
3. **الشريط العلوي المكتبي (Desktop Header Bar)**:
   - محرك بحث شامل وسريع يدعم اختصارات لوحة المفاتيح (`Ctrl + F`).
   - شريط شريطي لحظي لأسعار الصرف (SAR / USD مقابل الريال اليمني YER).
   - شارة الأمان والاتصال المشفر (256-bit SSL Banking Protocol).
   - جرس التنبيهات والإشعارات السريعة.

---

## 📱 3. المزايا المخصصة لنسخة الهواتف (Mobile Edition - Android & iOS)

عند تشغيل التطبيق على الهاتف:
1. **شريط التنقل السفلي الفاخر (Floating Bottom Navigation Bar)**:
   - تنقل سلس بين الرئيسية، المحفظة، العمليات، والملف الشخصي.
   - دعم التمرير باللمس وPull-to-Refresh.
2. **الصلاحيات والأمان المتكامل**:
   - مسح بطاقات الهوية للتحقق الذكي (KYC) عبر الكاميرا.
   - مسح وتوليد أكواد QR للدفع السريع والتحويلات اللحظية.
   - دعم البصمة وبصمة الوجه (Biometric / Face ID) لتسجيل الدخول وتأكيد الحوالات.
   - دعم الاتجاه الكامل للغة العربية (Full Native RTL Support).

## 🚀 4. أوامر التشغيل والبناء (Build & Run Commands)

### أ) على نظام ويندوز المكتبي (Windows Desktop):
```bash
# الانتقال لمجلد المشروع
cd "C:\Users\pc\Desktop\فلاتر\تطبيق النجم\05_AL_NAJM_DEMO"

# تشغيل التطبيق مباشرة على الويندوز
flutter run -d windows

# بناء النسخة التنفيذية للويندوز (ملف exe جاهز للتثبيت والتشغيل)
flutter build windows --release
```
*يتم حفظ الملف التنفيذي المكتبي الناتج في مسار:*
`build\windows\x64\runner\Release\al_najm_wallet_demo.exe`

---

### ب) على هواتف أندرويد (Android Phones):
```bash
# تشغيل التطبيق على محاكي أو هاتف أندرويد متصل
flutter run -d android

# بناء حزمة تثبيت APK مستقلة
flutter build apk --release

# بناء حزمة متجر جوجل بلاي (App Bundle)
flutter build appbundle --release
```
*يتم حفظ ملف APK الناتج في مسار:*
`build\app\outputs\flutter-apk\app-release.apk`

---

### ج) على هواتف آبل (iOS iPhones):
```bash
flutter build ios --no-codesign
```
