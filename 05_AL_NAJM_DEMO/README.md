# تطبيق محفظة النجم الرقمية — النسخة الاستعراضية (Al-Najm Wallet Demo)

تطبيق واجهة محفظة شركة النجم للصرافة والتحويلات المالية، مبني باستخدام Flutter/Dart، مستخلص من النواة المفتوحة المصدر للمنظومة المالية، ومُهيّأ بالهوية البصرية الرسمية الكاملة لشركة النجم للصرافة (النجم بلس).

---

## 🌟 الهوية والمميزات المعروضة في الديمو

- **الهوية البصرية:** اللون القرمزي المعتمد (`#9E1B21`)، التدرجات الفاخرة، والشعار الرسمي لشركة النجم بلس.
- **التميمة الرسمية:** شخصية "النجم" الكرتونية مع الشعارات التفاعلية الترحيبية.
- **نمط الحساب:** حساب تجريبي آمن ومفصول كلياً عن أي أموال حقيقية (Demo Mode Only).
- **الخدمات الجاهزة للاستعراض:**
  1. استعراض الرصيد اللحظي بالريال اليمني، الريال السعودي، والدولار الأمريكي.
  2. إرسال واستلام الحوالات المالية الفورية.
  3. دفع المشتريات لنقاط البيع والصيدليات والمطاعم مع كشف تلقائي للنشاط وتوجيه التحية السياقية.
  4. كشف حساب تفصيلي مع إمكانية تصدير تقرير شهري بصيغة PDF.
  5. مسح رمز الاستجابة السريعة (QR Code).
  6. إدارة الأجهزة المتصلة والجلسات مع ضوابط الأمان الصارمة (حد أقصى 3 أجهزة نشطة، وحد أقصى 10 أجهزة تراكمياً).
  7. واجهة التحقق من الهوية الرقمية (KYC) ثلاثية الأبعاد.

## 🚀 طريقة التشغيل (Run Instructions)

### المتطلبات
- تثبيت Flutter SDK (الإصدار 3.0 فما فوق).
- جهاز محاكي (Android Emulator / iOS Simulator) أو هاتف متصل بوضع تصحيح USB.

### أوامر التشغيل
```bash
# الانتقال لمجلد الديمو
cd "05_AL_NAJM_DEMO"

# جلب الحزم والمكتبات
flutter pub get

# تشغيل التطبيق في وضع التطوير
flutter run
```

### لبناء حزمة APK للإطلاق:
```bash
flutter build apk --release
```
