# UI POLISH PROMPT

راجع التطبيق كمصمم UI/UX ومهندس Flutter.

لا تغير business logic.

افحص:
- spacing
- typography
- alignment
- visual hierarchy
- responsive layout
- RTL/LTR
- dark/light theme
- loading/error/empty states
- button states
- keyboard overflow
- accessibility

أصلح المشاكل فعلياً في الملفات.

لا تضف animation مبالغاً فيه.
استخدم animation فقط عندما يحسن فهم التفاعل.
حافظ على أداء التطبيق.
بعد التعديل شغّل analyze وtests.
