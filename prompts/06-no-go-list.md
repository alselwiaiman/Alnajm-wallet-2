# THINGS TO AVOID

تجنب تماماً:

- بناء payment system حقيقي داخل Demo.
- إدخال API keys داخل Flutter.
- استخدام بيانات بنكية حقيقية.
- تخزين كلمات مرور.
- نسخ كود ضخم من مصادر غير موثوقة.
- إنشاء ملفات ضخمة تحتوي كل التطبيق.
- وضع كل المنطق في main.dart.
- استدعاء الشبكة من Widgets.
- إضافة dependency لكل مشكلة صغيرة.
- تجاهل analyzer.
- تعطيل SSL certificate verification.
- hardcoded credentials.
- حذف اختبارات أو ملفات موجودة لتجنب الفشل.
- تغيير architecture بدون حاجة.
- إنشاء تصميم جميل لكنه غير قابل للاستخدام.
- تجاهل العربية وRTL.
- تجاهل الشاشات الصغيرة.
- استخدام أرقام مالية حقيقية أو جعل Demo يبدو كأنه خدمة مالية حقيقية.
