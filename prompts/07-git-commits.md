# GIT COMMIT PROMPT

عند اكتمال Feature، اقترح commit واضحاً بصيغة:

type(scope): short description

Types:
feat
fix
refactor
test
docs
style
chore

أمثلة:
feat(wallet): add demo balance screen
feat(transactions): add mock transaction history
fix(auth): handle invalid demo login
test(wallet): add repository tests

لا تستخدم commit عاماً مثل:
"update"
"changes"
"final"
