# Demo Data Rules

كل البيانات تجريبية.

مثال مفاهيمي:
User:
- id: demo-user-001
- name: Demo User
- email: demo@example.test

Wallet:
- id: demo-wallet-001
- balance: 1250.50
- currency: USD

Transactions:
- TX-DEMO-001
- TX-DEMO-002

## ممنوع
- استخدام بيانات أشخاص حقيقيين.
- استخدام حسابات بنكية حقيقية.
- استخدام أرقام بطاقات حقيقية.
- الادعاء بأن الرصيد قابل للسحب.
