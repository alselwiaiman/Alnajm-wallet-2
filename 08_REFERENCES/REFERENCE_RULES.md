# REFERENCE FILE RULES

## User supplied reference images

The supplied Jib images are visual references for:

- layout
- navigation
- card hierarchy
- balance presentation
- quick actions
- promotional composition
- spacing
- UX patterns

They are NOT source material for:

- source code
- logos
- proprietary assets
- trademark identity
- pixel-perfect reproduction

## Al Najm supplied images

The supplied Al Najm UI/reference image is the primary branded design direction.

The official Al Najm logo is mandatory for the branded demo.

If a required Al Najm asset is not supplied:

- do not invent a replacement logo
- use a documented placeholder if safe
- add the missing asset to `docs/MISSING_ASSETS.md`

## Image processing

Do not overwrite original reference files.

Keep originals in a references folder and use copies/derived assets in production assets.
